Hostile calibration tables for Pore Pressure Studio U2-002 (PL2). The harness
well ORACLE PP-1: MD below RKB, KB 30 m above sea level, mudline at 130 m MD,
vertical. Values are the oracle goldens' imposed pressures, so every file
lands on the prognosis.

- rft_mdt_tvdss_psi_semicolon_comma.csv: semicolons, comma decimals, TVDSS in m, psi, a -999.25 null and a "lost seal" row, a Type column.
- lot_fit_md_ppg_tab_units_row.txt: tabs, units in a second header line (Techlog/Petrel style), MD, EMW in ppg, LOT/FIT/XLOT in a Test column.
- mud_weights_md_sg_no_header.csv: no header (every choice declared), MD m, sg.
- rft_kpa_reordered_extra_columns.csv: pressure first, extra columns, units in brackets, an "n/a" row.
- rft_tvd_ft_psi.csv: TVD below RKB in feet.
